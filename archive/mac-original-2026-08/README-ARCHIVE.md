# Mac original, 2026-08-03

This is the first version of Little Sprout Stories that lived on the Mac, before the
GitHub version was rebuilt. Nothing here is used by the live site. It is kept so the
original sprite art (a different set of poses and crops), the first-draft books and the
three original games are not lost. The pages work if opened from this folder.

The live site is the files in the repo root.

Note: Book 1 was never on the Mac copy. The one here is GitHub's version, copied in so the archive index has no dead link.
